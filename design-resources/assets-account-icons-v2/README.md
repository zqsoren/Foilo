## 图标来源

- 12张1024×1024平台图标由 Apple App Store 查询接口返回的图片地址下载，已检查文件实际像素。每张来源、应用页和取用日期见 [brand-sources.json](brand-sources.json)。例如 [支付宝](https://apps.apple.com/cn/app/id333206289)、[蚂蚁财富](https://apps.apple.com/cn/app/id1025628019)、[腾讯理财通](https://apps.apple.com/cn/app/id1187801604)。
- 余额宝、花呗、借呗使用 [SVGLOGO 金融支付目录](https://svglogo.top/directory/金融支付) 的独立矢量标识。原始文件为 [yuebao.svg](yuebao.svg)、[huabei.svg](huabei.svg)、[jiebei.svg](jiebei.svg)，来源地址为该站 /library/pay/ 同名文件。这是第三方整理的标识，未声称官方最新版本。Figma里增加浅灰圆角方形底，不改变品牌路径。
- 29个通用图标为本轮原创SVG，黑底、白色线条，64×64视框、14px圆角、2.6px线宽。名称与文件映射见 [catalog.json](catalog.json)，没有复用手机参考图的黄色图形。
- 平台子服务采用所属平台高清标识：余利宝、小荷包用支付宝；微信零钱通、微信分付用微信；京东小金库、京东白条用京东金融；美团月付、抖音月付分别用美团和抖音。名称区分具体账户。这些不是独立子服务Logo，后续取得独立来源时应替换图标主组件。
- 品牌商标归原权利人；本目录记录来源及设计选用，不代表自动接入或品牌授权。
