# iPhone 今日计划小组件

入口：`/todo/widget`（需要登录）；日程首页右上角「小组件」。

## 手机安装

1. 从 App Store 安装 Scriptable。
2. 设置页复制脚本，在 Scriptable 新建脚本，粘贴并命名「今日计划」。
3. 设置页生成并复制连接码。运行脚本，粘贴连接码；验证成功后存入 iOS Keychain。
4. iPhone 桌面添加 Scriptable 小组件，选小／中／大尺寸，编辑小组件并选择「今日计划」。

脚本使用 `ListWidget.url` 打开 `/todo`，不直接修改日程。缺少连接码时先在 Scriptable 运行脚本。连接失效后在网页重新生成，再运行脚本选择「更换连接码」。

## 数据与权限

- `todo_widget_tokens`：每个用户一个 SHA-256 哈希凭证，365 天过期；重发立即替换，停用立即删除；用户停用后凭证无效。
- `/api/todo/widget/access`：登录会话管理；写请求必须带同站 Origin。GET 仅返回状态，POST 仅首次返回新明文，DELETE 撤销。
- `/api/todo/widget`：只接受专用 Authorization Bearer，只返回该用户北京时间当天的展示字段。不能读取其他日期、备注、聊天或 AI 配置，不能写入。cookie 和查询参数不能替代凭证。
- 所有接口 no-store；脚本固定 HTTPS 域名，不接受跳转，不把连接码放入 URL 或日志。
- 支持重复日程、单日例外和完成状态；未完成优先，最多返回 20 项，统计使用完整当天数据。
- 脚本不在本地持久保存任务内容。网络故障或凭证失效后成功运行的刷新会显示恢复提示。iOS 已渲染的桌面快照可能保留至下一次系统刷新。

## 刷新与验证边界

脚本建议 15 分钟后刷新，实际由 iOS 调度，不保证准时或实时。显示北京时间日期和更新时间以识别旧快照；手机跨时区时仍按产品现有北京时间日程规则。

`tests/todo-widget.test.ts` 验证凭证隔离、轮换/撤销/过期、禁用用户、跨午夜、重复例外、数据裁剪和脚本原生 API 模拟。另已用本地实际 HTTP 接口测试权限边界及手机尺寸浏览器验证设置页。Scriptable 原生渲染和 iPhone 桌面后台刷新需真机安装后确认，浏览器预览不等同于真机截图。

部署沿用 `scripts/deploy-remote.sh`，必须把 `public/widgets/xipo-today.js` 随 public 目录一起打包；页面也读取此文件提供手势内直接复制，避免 Safari 异步请求丢失复制权限。

## DIGTODO 状态版本（2026-11-03）

网页和 Mac 列表圆圈：单击完成／恢复完成，双击推迟到次日，三击取消／恢复取消。
推迟会保留当日的已推迟记录，并原子生成次日无时间、无重复规则的新待办；重复任务只改当前实例。
完成、取消、推迟保留在原列表，待办数量只计算 pending，完成进度仍为 completed / 当日总数。

系统 WidgetKit 只执行按钮 AppIntent，不能可靠捕获连续点击。Mac 小组件圆圈完成，右侧 > 推迟、− 取消。
手机 Scriptable 中／大尺寸点击圆圈打开该任务的状态菜单，小尺寸整个组件只有一个点击目标，先选择任务。
Scriptable 操作后由 iOS 调度刷新，不能保证桌面瞬时刷新；使用原脚本需要替换为 v4。
旧连接码保持只读，新生成的连接码允许当天状态操作，需主动重发一次并替换原连接码。
服务端按令牌绑定账号，校验任务归属、日期、revision 和 requestId，不暴露聊天、AI 密钥。

再次双击已推迟项会取消推迟：恢复今天原时间，并撤回明天自动生成的未编辑副本。
如果明天副本已改标题、备注、日期、时间或已完成／再次推迟，则拒绝自动撤回以保护后续改动。
再次三击已取消项恢复为待办。系统小组件使用对应的箭头／短横按钮切换，手机脚本菜单提供“取消推迟”。
