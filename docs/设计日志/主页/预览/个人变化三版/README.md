## 示例数据与可视化口径

[合成数据](素材/示例数据.json)，非用户数据：2026-01-01至11-17，287个有记录日，98次训练、689项完成日程、48次资产记录，合计835。之后日期为未来，不计入统计。

- [年度热力SVG](素材/年度热力.svg)：每格一天，周一至周日由上到下，2026-01-01从周四开始；0、1–2、3–4、5–6、7及以上记录五档，未来留白。
- [生活星云SVG](素材/生活星云.svg)：835个主点对应记录，模块决定不同分布区域，时间决定从中心向外的位置并叠加少量视觉抖动；较近记录更明亮。引导环与光晕仅为辅助，不计入记录。
- [变化地形SVG](素材/变化地形.svg)：从1月1日起按7日段汇总，末段只含截至11月17日的数据；先按相邻1:2:1权重平滑，各模块再除以自身最大值。三个模块之间插值形成30道线面，额外线面不代表额外模块或数据。高度只能表达各自相对活跃程度，不用于比较领域价值或生活质量。

数字、统计与图形使用同一份样例；真实数据接入、缺失值、低记录量、历史修订与隐私策略尚未设计。源SVG及JSON同步仓库，页面文字和入口仍是Figma原生可编辑图层，PNG不是完整源文件备份。另一设备访问Figma尚未验证。
