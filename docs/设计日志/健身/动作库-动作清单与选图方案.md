# 健身动作库 · 候选清单与选图方案

2026-11-11 讨论稿。当前交付为中文动作目录与选取流程，供手机端评审。动作与图像尚未导入产品。首页沿用已确认的 01 稿。

## 从一份真实计划开始

以首页「上肢 A」为例。点「新建计划」直接进入动作库，依次选平板杠铃卧推、宽握高位下拉、坐姿绳索划船。即使从胸切到背、再输入“划船”，底部也一直显示「已选 3 个 · 加入计划」。确认后在计划编辑里看到这三行动作，可以改顺序、给每项设组数、给计划命名。下次点首页的「上肢 A」仍然直接开练。这里选取的具体器械和握法是示例，历史稿只写「高位下拉」时，不能据此回填握法。

## 分类怎么用

- **第一层按人找动作时说的话。** 常用入口为胸、背、肩、手臂、腿、臀、核心、全身。首页搜索可跨全部部位；有氧、热身与活动度、颈部专项作为扩展入口，等确认收录范围再决定是否露出。
- **第二层给肌群，同时提供动作别名。** 肩下列三角肌前束、中束、后束、肩袖与肩胛控制；手臂下列二头、三头、前臂与握力，屈肘类还能搜肱肌、肱桡肌。背下列背阔肌、大圆肌、菱形肌、上斜方肌、中下斜方肌、竖脊肌。从「大圆肌」可找到高位下拉、直臂下拉等相关动作，在详情标为参与肌群。肌肉可以共同参与同一动作，界面不承诺孤立某一小块肌肉。[OpenStax 上肢与肩带解剖](https://openstax.org/books/anatomy-and-physiology/pages/11-5-muscles-of-the-pectoral-girdle-and-upper-limbs)
- **其他部位的子筛选。** 胸用胸大肌及上胸侧重；腿用股四头肌、腘绳肌、内收肌群、小腿后侧、胫骨前肌；臀用臀大肌、臀中／小肌；核心用腹直肌、腹斜肌及躯干稳定。全身、有氧、活动度用动作类型细分。胸推会用到三头、硬拉会用到竖脊肌，主要浏览归属与辅助参与分别记录。
- **器械是独立筛选。** 徒手、杠铃、哑铃、壶铃、绳索／龙门架、史密斯、固定器械、弹力带、单杠／双杠、悬挂器材、其他。卧推凳之类可作配套器材。选「肩 → 中束 → 哑铃」可以找到站姿、坐姿侧平举；切到「绳索」后才出现单臂绳索侧平举。「常用」按我的使用记录取数，「收藏」由我主动设置，和器械分开。
- **每个动作保留一个身份。** 「坐姿绳索划船」可在多个肌群下出现，选中状态和历史记录共用一个动作 ID。「坐姿划船」可同时搜到绳索版、固定器械版；「硬拉」可同时搜到传统硬拉、罗马尼亚硬拉。搜索时优先匹配规范名，其次是俗称、英文缩写和相关肌群。RDL → 罗马尼亚硬拉，OHP → 站姿杠铃推举，面拉／Face Pull → 绳索面拉。
- **区分变式的尺度。** 下表把常见且值得独立比较负重的器械、角度或支撑方式列为独立条目。普通握距微调、座椅档位、训练节奏先写进个人备注。将来确有独立追踪需要时再拆，同一个人更换器械也可以做标记。

## 从 265 项里先拿哪些试用

首批优先用首页已有的六个动作名验收：杠铃卧推、高位下拉、坐姿划船、深蹲、罗马尼亚硬拉、坐姿腿弯举。再用哑铃侧平举、绳索面拉、杠铃弯举、绳索下压、杠铃臀推、平板支撑、器械辅助引体向上和农夫行走，检验小肌群搜索、不同计量及缺图状态。这样能在少量样本上检验分类是否好用，再分批配图。

## 单条动作需要保留什么

| 字段 | 一条例子或保存约定 |
|---|---|
| 身份与名称 | 稳定 ID、规范中文名、英文名、别名、系统或个人来源。改显示名仍能找回过去记录。 |
| 浏览与检索 | 主要部位、主要肌群、参与肌群、动作模式、主器械与配套器材。例如宽握高位下拉归背，主要肌群为背阔肌，关联大圆肌与屈肘肌群，模式为垂直拉。 |
| 变式和重量口径 | 关联动作家族，但卧推、上斜卧推分别记录进步。哑铃注明单只重量，杠铃注明含杆总重；自重、额外负重、辅助配重分开存，辅助配重减少代表所需帮助减少。左右侧训练可记录每侧，计划摘要明确显示“每侧”。 |
| 默认记录方式 | 卧推用 kg × 次；俯卧撑用次，可加负重；平板支撑用秒；农夫行走用重量 × 距离；跑步可用时长与距离。计时、距离是目录扩展建议，现有逐组录入规则覆盖重量与次数。 |
| 图像与说明 | 缩略图、起始／结束姿势或短动图、器械与角度、替代文本、作者、原始链接、许可版本、署名文本、是否可改图和再分发、核验日期。缺图可保持文字行，仍能选取。 |

计划另存动作引用、用户排序、目标组数。每次训练另存实际完成的数据；动作改名、下架或个人删除后，既有训练仍可按当时的名称与计量口径回看。

## 选动作时的几个细节

1. 库在新建流程中承担**多选**。点击一行选中，再点取消；跨部位、搜索、器械筛选都保留已选项。从已选清单能移除和调序。第一次进入时提供常见动作；有使用记录后优先显示自己的常用动作。
2. 确认选择后才加入计划草稿；空选时不出现可提交的加入操作。已有计划再次添加时显示「已在计划」，避免重复点击多加一条。计划草稿放弃时不产生训练记录。离开时已有未提交选择才询问是否保留。
3. 两个入口的写入目标分别显示为「加入计划」和「加入本次训练」。在新建计划这一支，动作选择先于命名。原有画板 11 → 07 的顺序需要在后续原型阶段核对；本次保留现行画板和连线。
4. 搜不到动作时先给出清除筛选和近似名称。仍找不到，可用搜索词新建**我的动作**，最少填写名称、部位、记录方式；器材、图片可后补。新建完成回到原选择并选中它；个人条目不自动写入全站公共库。
5. 区分「看图」和「选中」。图用于识别器械与姿势，查看详情后返回应保留列表位置。无图、图片加载失败或看不清缩略图时，都能通过名称、器械和简短动作说明选对动作。

**首轮选图建议**：先为首页的六个动作做一张匹配表，记录“规范动作名 → 图中的实际变式 → 来源与许可 → 可用／需补图”。例如「坐姿腿弯举」要能看出坐姿与垫轴，「俯卧腿弯举」即使训练相近肌群也需要另一张图。用户提供的两张截图作为信息结构和视觉参考；当前没有采购、转载或打包其中的插图。

## 本轮确认与待定

已记录的需求是从新建入口先挑动作、可多选并加入训练计划。首页上的按钮当前叫「新建计划」，本稿沿用这个名称。目录分组、动作覆盖范围、计时／距离、自定义动作、示意图来源均待评审。下一步先确认首版是普通力量训练优先，还是连同有氧和活动度一起开放，再安排配图和画板设计。
