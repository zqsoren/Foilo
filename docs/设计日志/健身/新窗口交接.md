## 端与发布

手机与桌面统一模块入口为 `/gym`。已完成实现，手机进入训练首页，桌面进入统计。共用登录、账号隔离、训练快照和容量口径详见[数据与登录](数据与登录.md)。首发目录为 100 项，17 项有授权图，其余保留图位。

2026-11-11 本地浏览器已验证注册、登录回跳、三张计划卡与新建按钮顺序、临时加动作、左右负重、计时、心得、刷新恢复、完成及日历统计；通过 101 项自动化测试。生产尚待 SSH 身份：当前电脑访问服务器被拒，公网 /gym 最近一次探测为 404。没有在生产修改数据库或切换流量。

健身增量的参考提交为 `e6bb9a7`，其 [Linux 构建验收](https://github.com/zqsoren/Foilo/actions/runs/43036969809)仅对应 GitHub 副本。用户指定服务器上的完整代码为发布基准。当前断点为 Windows 独立 SSH 公钥待原电脑授权。

授权后先只读核对 `/opt/life-workbench`、当前发布指向和完整源码位置，区分源码与 standalone 运行包。将相应源码下载到独立本地目录，保留服务器独有文件与修改，再逐项合入健身增量；服务端已有的登录回跳、数据库迁移编号和依赖需以实况协调。重新测试、构建匹配服务器的业务包后，按服务端核实的 `scripts/deploy-remote.sh` 备份、备用槽切换并验收公网。数据库、凭据和环境文件留在服务器各自的位置。此前 GitHub 整包不能直接作为该次生产发布包。
