## 实现、上线与验证

- **正式地址**：[在侧 Folio 宣传页](https://life-152-32-131-4.nip.io/folio/)。产品版本 `1.11.5`，静态服务器发布编号 `20261117-04`。版本记录在 HTML meta 和线上原有页脚版本位置。
- **代码**：[HTML](../../../folio-landing/index.html)、[基础样式](../../../folio-landing/site-assets/site.css)、[排版](../../../folio-landing/site-assets/layout.css)、[动效样式](../../../folio-landing/site-assets/motion.css)、[动效脚本](../../../folio-landing/site-assets/motion.js)、[账号菜单](../../../folio-landing/site-assets/account.js)。此前已从线上取回未入库的字体、字标、样式和脚本，保留已有功能，没有新增依赖。
- **本轮约定**：用户明确要求不修改 UI 原文、不添加「功能预览」或接入范围标注。用户明确说明手机适配不需要，本轮以桌面为交付和验收目标。现有窄屏兜底样式保留，不视为手机端定稿。
- **动效**：保留线上 `1.11.3` 的分区进入、时钟开关、模块卡片悬浮、AI 顺序与逐字显现等效果；支持系统减少动态效果。健身及资产入口使用原生链接，无需 JavaScript。
- **交互**：「登录」进入共用 `/login`；首屏「使用网页版」进入 `/`，访客经主页登录门禁进入 `/login`，已登录用户直接进自己的主页。资产在当前可用组第三位、收支在规划中组第三位，资产整卡进入 `/wealth/dashboard`，访客回跳参数保留该路径。TODO 原有卡片链接仍为 `/todo/dashboard`。健身整卡原生链接指向 `/gym`，保留同一标签页及既有会话；桌面登录后到 `/gym/dashboard`，手机进入训练页。访客登录回跳分别保留 `/gym?device=desktop`、`/gym?device=mobile`。其他锚点和停用下载保持原样。
- **本轮验证（2026-11-17，1.11.5）**：Browser plugin not available，使用既有 Playwright/Chromium。本地覆盖静态 HTML 与公网实页分别在 1440×900、390×900 检查页面标题、正文、八卡顺序、版本与链接、无横向溢出，截图复核排版。点击使用网页版进入 `/login`；资产桌面键盘回车、窄屏卡片空白点击进入 `/login?next=%2Fwealth%2Fdashboard`，手机号输入框可见。页面运行错误与非预期 HTTP 失败均为 0，访客会话 401 为预期。未重新登录账号写入业务数据，已登录主页和资产流程沿用业务发布验收。
- **此前健身入口验证（2026-11-17，1.11.4）**：Browser 插件不可用，使用已有 Playwright/Chromium；本地与公网 1440×900、390×844 均通过页面身份、非空、八张卡片、无框架错误页、素材加载、无横向溢出检查。卡片宽高、字体、颜色、文案与发布前线上基准一致；桌面键盘聚焦回车、手机点击卡片空白处进入正确登录回跳。无运行错误和非预期失败请求；访客会话接口 401，以及旧账号脚本切换页面时取消请求属于预期。公网未新建/登录测试账号，已登录业务流程沿用健身本轮既有验收。两份脚本 `node --check` 通过；字体原许可文件保留上游空格。
- **历史整页验证（2026-11-11）**：Chrome 桌面 1280、1440 无横向溢出，20 张素材、锚点、两处登录、下载停用、键盘、减少动态效果和禁用 JavaScript 检查通过，详见历史日志。本轮没有重新执行其中全部场景。
