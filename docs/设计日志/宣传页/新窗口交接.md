## 实现、上线与验证

- **正式地址**：[在侧 Folio 宣传页](https://life-152-32-131-4.nip.io/folio/)。产品版本 `1.11.1`，服务器发布编号 `20261111-03`。版本记录在 HTML 的 `folio-version` meta 中，不增加页面可见文字。
- **代码**：[HTML](../../../folio-landing/index.html)、[样式](../../../folio-landing/site-assets/site.css)、[动效](../../../folio-landing/site-assets/motion.js)。独立静态页面，沿用已有字标、应用图标、时钟、八个模块插画、泳池图和六款 AI 图标。没有新增依赖。
- **本轮约定**：用户明确要求不修改 UI 原文、不添加「功能预览」或接入范围标注。用户明确说明手机适配不需要，本轮以桌面为交付和验收目标。现有窄屏兜底样式保留，不视为手机端定稿。
- **动效**：首屏浮签轻浮后在 5 秒内停稳；记录簿、模块等进入视口时显现；总览柱图依次展开，AI 三栏依阅读顺序显现。使用 CSS 和 IntersectionObserver，无滚动监听劫持。系统减少动态效果、键盘导航、脚本失败时保留完整可读内容。
- **交互**：「登录」「使用网页版」实际点击后均进入共用 `/login`；产品、定价、MCP 服务为页内锚点；桌面下载保持停用。
- **验证**：本地 Chrome 桌面 1280、1440 宽度无横向溢出；20 张素材正常加载；八张卡片说明无溢出；无页面运行错误。检查过页内定位、两处登录跳转、下载停用、键盘入口、减少动态效果、禁用 JavaScript 时正文可读。公网 Chrome 已复核首页 HTTP 200、20 张素材、无横向溢出、MCP 锚点和登录跳转，页面错误与失败请求均为 0；原登录字体、图标及业务健康接口均为 200。
- **金额**：With AI 的 AI 回复和账本保持 148 元，单笔支出为 32 元。Figma 当前仍有 120 / 148 的原稿差异，本轮不改 Figma 文案。
