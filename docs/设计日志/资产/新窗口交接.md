## 结构草案（待评审）

### 三个主页面（分工已确认，名称与布局为建议）

用户明确将原建议中的录入与明细拆开，形成三个独立页面：

1. **数据概览**：模块首页，读取全部已录入数据，展示汇总与分析；不承载填写或修改表单。
2. **数据录入**：集中添加账户、资产和负债，并更新已有记录；按类别显示适用字段。
3. **资产总览**：完整展示每个资金账户、每笔资产及负债，支持查找、筛选和逐项查看。

共用导航建议固定为「数据概览 / 数据录入 / 资产总览」。看板和总览读取同一份已保存记录，草稿不进入统计；保存后可继续录入或前往总览定位新记录。页面具体路由待确认。

### 数据概览：小组件与布局建议

顶部放统计截至日期、汇总币种、金额显隐；历史图单独提供时间范围。汇总数字显示截至日期的最新有效估值，不随图表范围被误解为期间流水。

| 组件 | 展示内容与形式 | 数据条件／边界 |
|---|---|---|
| 资产摘要 | 总资产、总负债、已记录净额三个重点数字；有可比历史时显示较上次变化 | 展示统计范围；未填写不等于零；有缺失汇率或估值时标识汇总不完整 |
| 资产变化 | 宽幅趋势图，净额为主，可切换资产／负债；按月或按年查看 | 至少两个有效历史时点；仅一次记录时提示等待后续记录，不生成虚构曲线；不标为收益 |
| 资产构成 | 横条展示现金与存款、基金、股票、理财、债券、贵金属等金额和占比 | 使用互斥类别；不与账户层汇总重复相加；负债另列；无完整折算时提示占比范围 |
| 账户分布 | 按银行／平台汇总，可展开账户；横向金额条与账户数量 | 机构与账户是两层；同机构不同尾号分别保留；长列表显示前几项及查看全部 |
| 投资构成 | 仅投资部分的类别金额与占比 | 无投资记录时不显示全零图；首版可作为候选，避免与资产构成重复占据首屏 |
| 币种分布 | 人民币、美元、日元等原币金额，以及统一折算后的占比 | 不直接相加不同币种；标明折算币种、汇率日期与缺失项 |
| 负债概况 | 各类当前欠款、最大负债项；可选显示负债／已记录资产 | 无记录时提示尚未录入；资产为零时比例不可算，不显示无限大或健康评分 |
| 更新状态 | 账户最近更新日期、待更新条目、未完成估值的记录 | 可跳转总览查看或录入页更新；提示周期待确认，不默认认定所有记录应每日更新 |
| 到期事项（条件组件） | 定期／理财到期、信用卡还款日、贷款下次应还事项 | 需先支持相应日期及应还金额字段；不从总欠款推算下期应还金额 |

默认布局建议：第一行资产摘要；第二行宽幅资产变化 + 资产构成；第三行账户分布 + 币种分布 + 负债概况；页尾轻量更新状态。投资构成和到期事项放候选组件池，不默认把全部组件堆进首页。各区域大小随内容需要分配，不要求等大卡片。是否支持用户拖拽、添加与移除组件未确认。

点击类别或账户分布，可跳到资产总览并带入对应筛选。首页只读取、展示和导航。

### 数据录入：集中填写与连续录入

建议左侧为类别入口：现金与存款、投资、其他金融资产、负债；中间为主要表单；右侧窄栏展示「本次已保存」摘要，便于连续录入核对，不替代第三页的完整清单。

- **新增一笔**：选类别 → 选已有账户或新建（机构、昵称、尾号）→ 名称、原币金额、币种、记录日期 → 按类别展开可选字段 → 保存并继续／保存并查看。
- **更新已有记录**：先选账户与条目，再更新余额或市值及日期；保留历史，避免把每次更新误建成另一份资产。余额快照模式尚待确认，结构草案暂按此演示。
- 银行记录重点是机构、尾号、币种、余额；投资重点是名称、类别、持有账户、当前市值；负债重点是债权机构／对象、类别、当前欠款。到期日、成本、数量等按需展开。
- 账户在表单中就地建立，不增加第四个主页面；先有现金记录的用户不必填写银行或卡尾号。
- 保存前清晰显示账户和币种；保存失败保留输入，未保存内容离开页面时提示。错误位置紧邻对应字段。所有具体布局、字段必填性和交互仍待用户确认。

### 资产总览：完整持有清单

顶部建议为搜索、资产／负债筛选、类别筛选、币种筛选；提供「按账户 / 按类别」分组方式。默认按账户分组，用可折叠表格展示大量条目，尽量不为每一笔资产铺一张卡片。

- 账户组头：机构、昵称、尾号及折算小计；组内行展示名称、类别、原币金额、折算金额、记录日期。
- 资产与负债分区呈现。账户内同时有资产和负债时分别给小计，不悄悄相抵；总览清楚显示统计范围。
- 点击一行打开右侧详情，展示完整字段、备注、历史估值；「更新这笔」跳转数据录入页并带入该条目。明细详情先用抽屉，不额外增加主页面。
- 账户组小计只用于展示，不再与组内金额相加。未估值、缺汇率、历史记录较旧的状态直接标在对应行。
- 无记录时引导前往数据录入；筛选无结果时提供清除筛选。隐去金额时，总计、明细、图表提示同步处理。

### 三个独立维度

- **账户：在哪里**。机构 + 账户昵称 + 可选尾号，例如「工商银行 · 工资卡 · 1234」。机构提供常见选项与自定义；尾号用来辨认，不作为唯一标识。无需完整卡号。
- **类别：是什么**。存款、股票、基金等。一账户可以包含不同类别；银行不是资产类别。
- **币种：用什么货币计价**。人民币 CNY、美元 USD、日元 JPY 等。同一账户可以有多币种条目。持有美元存款仍归存款；外汇交易属于另一种业务，不能把币种选择等同于外汇投资。

### 建议分类

| 大类 | 初始子类／记录内容 |
|---|---|
| 现金与存款 | 现金、银行活期、银行定期、大额存单、支付账户余额、证券账户闲置资金 |
| 投资 | 股票；基金；债券；银行理财；直接持有的黄金／贵金属；其他投资 |
| 其他金融资产 | 预留自定义入口；如借出款、保险现金价值等，是否首版支持及估值口径待确认 |
| 负债（单独统计） | 信用卡欠款、房贷、车贷、消费贷款、个人借款、其他负债 |

基金可按投资方向分股票型、债券型、混合型、货币型等；ETF、指数型作为独立属性，不能与上述分类硬设为互斥项。黄金 ETF 归基金，直接持有黄金归贵金属，不能重复计入。银行销售的基金、理财与存款分别记录。

私募、信托、期货、期权等可后续扩展专门结构，首版不默认展示复杂输入。衍生品涉及保证金和负债，不能简单把名义合约金额当作资产价值。

### 记录与计算建议

- 首版建议采用**定期余额快照**：记录今天持有多少及价值多少；买卖、转账和完整交易流水待后续决定。每次更新保存日期和历史，修正错误与新增一次估值区分处理。
- 存款填写当前余额；投资先填写当前市值，成本、数量和单位价格可后续按类别展开，不用强制填写整套交易资料。
- 多币种保留原币金额，暂建议人民币为汇总币种；汇率来源、时间及自动／手动方式待确认。缺汇率时保留原币并明确汇总不完整，不按零计算。
- 账户汇总由明细相加，不能把账户总余额与其中已拆出的基金、定期等再加一次。若提供仅填账户总额模式，需标明未分类，禁止与完整明细重复汇总。
- 汇总使用选定日期以前各条目最近一次估值，显示估值日期及陈旧提示；历史汇率与历史估值保留口径，不能无提示地用今日汇率重算历史。
- 净额 = 已记录资产 − 已记录负债。范围仅金融资产时，不称为完整家庭净资产；例如只记房贷、未记房产，必须提示统计范围。
- 资产变化不等于投资收益，可能包含存入、支出、增删记录和汇率变化。仅有余额快照时不展示推算的投资收益率。
- 信用卡记录欠款，授信额度不计入资产；贷款记录当前未偿余额而非最初借款金额。保险若纳入，需要确定可实现现金价值口径，保额不能直接记作资产。
