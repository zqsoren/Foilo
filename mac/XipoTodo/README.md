# Xipo 日程 · Mac 桌面伴侣

首版支持 Apple Silicon（M1/M2/M3/M4 等）、macOS 14 及以上。

## 开始使用

1. 打开 `output/mac/Xipo-Todo-Mac-arm64.dmg`，把「Xipo 日程」拖到「应用程序」。也可解压 ZIP 后拖入。首次打开应用会显示主窗口和悬浮球；关闭主窗口后悬浮球仍会保留。
2. 在 Mac 设置窗口中直接输入人生工作台的手机号和密码，点击「登录」。无需 API Key、MCP 或手动复制连接码。
3. 登录后会同步同一账号的日程。密码不落盘；登录凭证保存在 macOS 钥匙串。
4. 设置中「退出登录」会撤销这个 Mac 的服务器会话并清除本机凭证，不删除日程，也不影响手机会话。
5. 在桌面空白处点右键，选择「编辑小组件」，搜索「Xipo 日程」并添加。可选小、中、大三种尺寸；位置和排列由 macOS 管理。

这是本机开发版。主窗口的「更新应用」按钮会从当前项目代码重新构建、替换「应用程序」中的版本并重启。项目需要留在本机原位置，且安装了 macOS Command Line Tools；这不是联网自动更新。当前应用使用此 Mac 专属的本地签名证书，后续更新可保持同一应用身份和钥匙串授权。以后要给其他 Mac 在线更新，仍需要 Apple Developer ID 签名、公证和发布源。

从旧版临时签名构建升级到 1.2 时，Mac 端可能需要重新登录一次。手机账号和日程数据不变；后续使用同一本地证书签名的更新可以保持授权。

这是本机构建、自用版本，采用此 Mac 的本地签名，未进行 Developer ID 公证，也没有上架 App Store。本机可直接运行；不建议关闭 Gatekeeper 等系统保护。DMG 适合当前 Mac 安装，不能当作面向其他 Mac 的正式安装包分发。

## 操作

- 系统原生小组件采用白底左右分栏：左侧橙色日期和已完成、未完成数量，右侧显示今日任务。它在 macOS 小组件层内排布，不会以独立窗口覆盖系统的小组件。
- Mac 应用在后台运行时，小组件中的未完成圆圈可直接点击完成任务，随后同步账号、主界面和完成数量。已完成任务保留勾选；任务按时间排列。旧日期、已退出账号或过期会话的缓存按钮不会写入任务。
- 主界面显示今日计划、完成进度和刷新、设置、AI 助手与本机更新入口；点击程序坞图标可重新打开。
- 悬浮球显示未完成数量，拖动球可移动，点击以动画展开为窄竖列；顶部箭头收起，底部省略号打开主界面。右键球打开设置。
- 竖列中每个编号圆球代表一项任务：单击展开标题和时间，再次单击收起；双击标记完成，再次双击取消完成。单双击互斥，双击不改变详情展开状态。已完成圆球变灰并显示勾选，保留原来的时间顺序和位置。详情根据球的位置向屏幕内侧展开，系统开启减少动态效果时缩短动画。
- 主界面可勾选圆圈完成今日未完成任务；任务列可双击切换当天完成状态，点击主界面任务标题查看时间和备注。
- 日程列表末尾始终保留一条空心圆空白行。点击后输入标题，下方展开单行备注和同一行的小号日期、开始、结束控件；日期默认当天，开始向上取十分钟，结束默认一小时后。回车或点击行外自动保存；空标题不创建任务，失败保留输入。保存后同步当前账号并刷新列表、小组件。⌘N 可直接定位这条输入行。
- 完整编辑和 AI 对话通过按钮进入现有网页。
- 展开面板可滚动查看全部日程。小组件根据尺寸显示部分任务，点击可展开 Mac 待办面板。
- 设置可显示/隐藏悬浮球及恢复球的位置。菜单栏图标始终提供设置与退出入口。
- 开机启动通过系统登录项实现，默认关闭；先移入「应用程序」再开启。需要时在系统设置允许。
- 日程采用北京时间，运行期间每 60 秒同步，唤醒和展开时刷新，也可手动刷新。休眠或离线不承诺及时同步。
- 网络失败时保留同一天的上次内容并标注错误，暂停写入；跨午夜清除过期的当天快照。登录失效时清空显示，重新登录。
- 退出应用后悬浮球关闭，小组件保留今日最后一次成功读取的内容；下一次启动会重新同步。退出登录会清除主应用中的快照并请求系统刷新小组件，实际刷新时间由 macOS 决定。

## 构建与检查

只需 macOS Command Line Tools，无额外依赖。`build.sh` 编译 SwiftUI/AppKit 主应用和 WidgetKit 扩展，生成 `.app`、ZIP 和 DMG。小组件必须使用系统扩展入口启动，否则 macOS 26 会在读取组件信息前将其作为普通程序退出。`make-icon.swift` 生成代码绘制的暖橙图标。

- `Sources/API.swift`：固定 HTTPS 源、禁止重定向、无 Cookie/HTTP 缓存的账号客户端，手机号密码登录、会话 Cookie、revision 与 requestId；钥匙串。
- `Sources/Store.swift`：内存状态、自动刷新保护、账号切换隔离、完成操作与小组件快照更新。
- `Sources/WidgetSnapshot.swift`：仅存放用于显示的日期、标题、时间和完成状态，不共享会话或密码。
- `Sources/WidgetBridge.swift`：只在本机回环地址提供展示快照和完成动作，用每次构建生成的随机令牌限制访问；完成动作还需匹配当前账号会话上下文和日期，账号登录凭证留在主应用。
- `widget-intent-metadata.py`：CLT 构建中为单一小组件 App Intent 生成元数据，并从编译后的符号核对类型名称及四个 String 参数。
- `Widget/TodayWidget.swift`：原生小组件的时间线、暖橙界面与今日快照缓存。
- `Widget/Entitlements.plist`：小组件沙盒只获得网络客户端权限；不保存人生工作台登录凭证。正式签名分发时可改为 App Group 共享容器。
- `Sources/Views.swift`：悬浮球、展开列表、设置、详情。
- `Sources/App.swift`：悬浮球位置恢复、菜单栏、定时刷新和小组件点击跳转。
- `Tests/APITests.swift`：隔离 URLProtocol 模拟，检查登录、会话、完成参数、重复单次、冲突、退出和错误。
- `Tests/Integration.swift`：仅供本机隔离测试库，真实账号 HTTP 登录/读取/完成/并发冲突/退出验证。不能传生产账号。

`--demo` 或独立 `io.xipo.todo.preview` 预览包只使用示例数据，不读取钥匙串或联网，界面标注示例预览。
